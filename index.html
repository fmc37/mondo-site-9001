One prompt, 100+ brands: the quality system behind it

One production prompt powered AI sales and support for more than 100 ecommerce brands, spanning $500M+ in GMV and thousands of conversations a day. A single bad edit could reach every brand at once, so I built the evals that every change had to pass.

What I built

  • The entire LLM eval pipeline: a failure taxonomy, LLM-as-judge scoring (a model grading responses against a rubric), and regression tests.
  • Two severity tiers every change was tested against: P0 for failures that could put a customer relationship at risk, P1 for issues customers would immediately notice.
  • A daily review of live conversations that turned each new failure into a tailored eval and validated every fix against the original generations.
  • Ownership of the production prompt, with peer review before promotion, so nothing reached production without passing the evals.

Example: made-up discounts

The failure: Engineering shipped a feature for Black Friday and Cyber Monday promotions, but the promo details reached the prompt as a raw dump through a conditional merge tag. The agent advertised the sale with percentages it made up.

The fix: I worked with Engineering to restructure the injection into an explicit list of active offers, which became the source of truth for the judge. If the agent offered anything outside that list, the response was regenerated, and if it kept happening, the agent failed gracefully.

Also shipped: A major compliance update that let us sell and advertise supplement brands, plus releases for promotions and escalation logic on tight timelines.
